# trabajo-enfoque-diseno-medac

Sitio web de supermercado formado por un menú de navegación con página principal, iniciar sesion/registrase, añadir productos a favoritos, añadir al carrito; también una lista desplegable donde están ordenados los productos por categorías.
En la zona de aterrizaje se puede ver distintos banners con promociones, productos favoritos de los clientes y fidelización.

## Características principales:

- Enfocado en el diseño y la experiencia de usuario. 

- Animaciones sutiles al desplegar menús o botones.

- Sistema de filtros y búsqueda de productos.

- Diseño limpio y minimalista con tipografía legible.

- Paleta de colores atractiva y consistente (rojo para botones y header).

- Diseño responsivo adaptado a móviles, tablets y desktop.

- Compatible con todos los navegadores modernos.

# Herramientas utilizadas:

* Figma para el diseño de la web y el ícono del supermercado.

* HTML5, CSS3, JS(ES6), no se ha usado framework.

* VSCode.

* Freepik para las imágenes de los productos.

* Google Fonts para tipografía.

* Font Awesome para iconos.
